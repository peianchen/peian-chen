P.02PUBLIC / IMAGING

BIOLOGICAL IMAGING

SpaceCellCam

XIAO ESP32S3 與 OV5640 AF 定時取像韌體，預設每 10 秒擷取 QSXGA JPEG，整合 LED 照明、焦點鎖定重用、感測器待機與 microSD 儲存。

  • C++
  • ESP32-S3
  • OV5640
  • microSD
目的、實作與使用範圍
目的
持續記錄生物實驗影像，並降低每次重新對焦及長時間照明造成的負擔。
實作
首次對焦後重用鎖定狀態；影像先複製到 PSRAM，釋放 frame buffer 並讓相機待機，再以暫存檔、重新命名與檔案大小檢查完成寫入。
範圍
目前公開核心是取像與儲存韌體。對焦、溫升與供電表現需依實際光學配置測試，未宣稱完成飛行或環境認證。

P.04PUBLIC / ZEPHYR

LOW-POWER SENSING

nRF54L15 × MLX90614

以 Zephyr／nRF Connect SDK 在 XIAO nRF54L15 上讀取紅外線溫度，透過 BLE 傳送資料，支援每 60 秒取樣及手機要求即時量測。

  • C
  • Zephyr
  • nRF54L15
目的、實作與使用範圍
目的

範圍

CURRENT FOCUS

Embedded systems × FPGA × intelligent sensing

博士與近期研發專案由我獨立開發，依專案範圍負責需求、架構、韌體與操作軟體、系統整合及測試文件；現有成果與開發中項目分別說明。

我從宜蘭大學生物機電工程，進入陽明交通大學生醫工程碩士班，再延伸至電機工程博士研究。這條路徑讓我同時接觸生物實驗需求、感測控制與軟硬體開發。

實作涵蓋 Nordic nRF、ESP32、Raspberry Pi、Android／Wear OS 與 FPGA。除了讓裝置取得資料，我也處理離線保存、裝置識別、資料同步與異常紀錄，讓實驗流程更容易操作和追蹤。

ThermoPatch 的後續 V2 平台進一步以 Room 保存本機歷史和各裝置同步進度，將 BLE 取回資料與 Firebase 上傳分開，處理待傳佇列、背景重試和多裝置輪流同步。V2 與汗壓研究程式未公開，網站僅介紹用途與工程工作。

目前聚焦低功耗穿戴式感測、BLE 多裝置資料流程及 Verilog RTL，並持續研究邊緣運算與 TinyML。設計選擇會連同測試條件、模擬結果和未完成項目一起記錄。
