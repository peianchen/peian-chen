ECsnap Electrochemical Instrument

ECsnap 電化學儀器

整合 EmStat Pico、微控制器、TFT 與 microSD，以單鍵流程完成穩定等待、計時安培量測、狀態回饋與 CSV 資料保存。

01 / PURPOSE

目的與用途

把電化學電流量測轉成便於操作及保存資料的可攜式研究儀器。

02 / ARCHITECTURE

系統架構

01

量測核心

EmStat Pico 執行電化學方法，透過 MethodSCRIPT／UART 與微控制器交換資料。

02

控制與解析

嵌入式程式將啟動、等待穩定與量測結束組成狀態流程，解析回傳電流與狀態。

03

操作回饋

TFT 顯示階段與資料，讓使用者能辨識儀器是否仍在等待或已完成。

04

資料保存

RAM 緩衝與 SPI 共用管理協調 TFT 和 microSD，將結果保存成 CSV。

03 / WORKFLOW

操作流程

01開始一次量測

單鍵進入既定方法，將操作者動作轉成可追蹤的儀器狀態。

02等待與執行

安排穩定等待及計時安培法，透過串列介面接收量測回傳。

03解析與更新

將有效資料轉為顯示與記錄項目，協調畫面刷新和儲存工作。

04完成與保存

結束量測後保留 CSV，供後續檢查時間序列與分析條件。

04 / EVIDENCE

成果與圖像

儀器整合

已整理 EmStat Pico、微控制器、TFT 與 microSD 的操作與資料流程。

平台移植

研究工作涵蓋 SAMD21 至 nRF52840 的平台移植，重點包括串列解析、周邊管理與資料保存。

可展示內容

本頁以儀器原型與操作架構說明整合成果；濃度校正需搭配指定分析物與實驗方法。

05 / ANALYSIS

分析與判讀

讓儀器狀態可見

電化學量測包含等待與執行階段。清楚的狀態回饋能協助定位未啟動、仍穩定中或資料未保存的差異。

共享匯流排需要排程

TFT 更新和 SD 寫入若同時爭用 SPI，可能影響資料服務時機；緩衝與批次寫入讓量測接收和畫面更新更易協調。

由電流走到濃度

CSV 量測鏈完成後，仍需以空白、標準品及指定電極條件建立校正，才能討論分析物濃度與檢出能力。

06 / REPRODUCE

閱讀與重現

  1. 從儀器組成與操作流程閱讀量測鏈。
  2. 檢查方法設定、時間欄位及狀態回傳是否對應。
  3. 分析 CSV 時先確認單位與量測條件，再進行校正或比較。

07 / LIMITS

範圍與限制

研究程式未公開。電流擷取與濃度換算分開處理，分析物校正及醫療診斷效能未視為已完成。
