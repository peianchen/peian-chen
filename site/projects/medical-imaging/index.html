MEDICAL IMAGE ANALYSIS課程實作

Deep Learning for Medical Imaging

醫學影像深度學習

五份作業涵蓋 SPECT 與 MRI 分類、超音波頸動脈分割、胸腔 X 光異常區域偵測，整理前處理、PyTorch 模型、訓練結果與分析。公開程式與彙整圖表，不含病患資料。

01 / PURPOSE

目的與用途

比較分類、影像分割與物件偵測如何對應不同的醫學影像任務。

02 / ARCHITECTURE

系統架構

01

資料任務

五份作業涵蓋數字、SPECT／MRI、超音波及 X 光，對應分類、分割與偵測。

02

前處理

依任務處理切片、體積、影像與標註，並注意切分單位。

03

模型

比較 MLP、遷移學習分類器、U-Net／FCN 及 Faster R-CNN。

04

評估

使用 accuracy、macro-F1、IoU／Dice 及 AP 等不同指標，連同資料條件解讀。

03 / WORKFLOW

操作流程

01定義預測問題

先決定標籤是類別、像素遮罩或框，再建立資料切分。

02訓練與保存

由 DataLoader、增強與模型迴圈保留訓練及驗證紀錄。

03比較指標

以符合任務的指標觀察訓練／驗證差距。

04核對來源

將保存的曲線、checkpoint 與評估集合相互對照，記錄限制。

04 / EVIDENCE

成果與圖像

數字分類

歷史第 25 epoch validation accuracy 98.08%、macro-F1 97.87%，不是另一次獨立測試集結果。

分割與偵測

HW4 最後 mean IoU 97.26%、Dice 98.60%；HW5 validation AP50 0.396、AP@[.50:.95] 0.222。兩項任務與資料切分不同。

泛化問題

SPECT oversampling 的 validation accuracy 51.52%、macro-F1 21.59%，顯示平均正確率不足以描述少數類別表現。

05 / ANALYSIS

分析與判讀

高分必須連同切分方式

HW4 採影格隨機分割，鄰近影格可能高度相似；因此其高 Dice 不應當作跨受試者泛化。MRI 的 93.75% validation 也僅來自 16 人。

不平衡資料需要更多指標

SPECT 的 accuracy 與 macro-F1 差距指出類別表現不均。重取樣有助訓練分布調整，但不能由訓練高分推論泛化改善。

保存輸出仍需程式核對

HW5 有 train-validation gap 與 CSV 座標待修正問題；結果曲線應連同評估與輸出格式檢查一起閱讀。

06 / REPRODUCE

閱讀與重現

  1. 從五份作業 README、FILES 與 RESULTS 理解資料與模型。
  2. 依 ENVIRONMENT 準備環境及有權使用的資料，公開版不含病患影像或模型權重。
  3. 先核對資料切分、標籤與指標，再嘗試重建訓練流程。
  4. 將新的訓練紀錄與歷史結果分開保存，特別記錄受試者與影格的切分單位。
