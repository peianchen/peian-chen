05 / ANALYSIS

分析與判讀

樹的問題定義不同

最短路徑樹最小化指定起點到各點的距離；最小生成樹最小化連接所有頂點的總邊權重。相似的樹形輸出不能互換解釋。

複雜度要看實際實作

此版 Dijkstra 使用線性搜尋，不應直接套用 heap 版本的時間複雜度；排序程式也含 GNU C 巢狀函式相容性條件。

測例通過與格式完整性

Huffman 檔案未保存解碼樹、計算器將未定義變數當 0 等限制，會影響可攜性與錯誤行為，不能由代表測例通過忽略。

06 / REPRODUCE

閱讀與重現

  1. 從九份作業索引選擇主程式，先閱讀 FILES 與已知限制。
  2. 使用 GCC GNU C11 編譯，在獨立目錄執行會寫檔的圖論或 Huffman 程式。
  3. 執行 tools/verify_course.py，對照原本的驗證條件。
  4. 分析歷史圖時保留資料大小與環境，勿直接當作目前電腦的效能數字。

07 / LIMITS

範圍與限制
