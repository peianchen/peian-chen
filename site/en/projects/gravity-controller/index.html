02 / WALKTHROUGH

Implementation in focus

From two motor angles to a time-averaged vector

  1. Establish a shared reference

    After startup zero-reference checks, a scheduler generates targets for both axes. Angle feedback and speed estimates need a shared time base to reconstruct orientation at the same instant.

  2. Track the motion target

    Feedforward supplies the base drive and PID corrects feedback error. Comparing control modes requires consistent mechanics, loads and sampling conditions so hardware changes are not mistaken for strategy improvements.

  3. Average vectors before taking magnitude

    The running-mean plot concerns the average of changing direction vectors, not the average of instantaneous gravity magnitudes. Directions can partially cancel in the model, reducing the mean magnitude without removing Earth's gravity.

The controller describes motion; the model interprets the orientation time series. Sample position, centrifugal effects and biological responses require their own experiments or models, not a running-mean plot alone.

06 / ANALYSIS

Analysis and interpretation

Use a shared time reference

Separate motor motion does not describe the spatial direction history. Schedule, angle and time need to be comparable.

Feedback exposes deviations

Feedforward supplies baseline drive while feedback corrects load and speed differences. Compare strategies with the same mechanism, load and sampling.

Connect motion to sample conditions

The controller describes mechanism motion. Sample conditions additionally depend on position, rotation center and experimental setup.

07 / REPRODUCE

Explore and reproduce

  1. Read schedule, control and feedback together.
  2. Check startup reference, units and time alignment between axes.
  3. Retain load and sample position when comparing modes, with the model or measurement used.

08 / LIMITS

Scope and limitations

Research code is private. Rotation is not true weightlessness, and control settings do not establish measured gravity conditions.
