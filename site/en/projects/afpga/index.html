05 / ANALYSIS

Analysis and interpretation

LEDs expose the whole chain

Lab 8 connects a Linux program, bridge, Avalon peripheral and physical pins. The display counts complete round trips, not LED position.

Read all timing calls

A Lab 8 step includes both a 100 ms and a 1 s wait, totaling about 1.1 seconds. A single comment does not describe total delay.

Build and timing evidence

A rebuild establishes tool compatibility. The record lacks SDC/clock constraints, so successful compilation does not establish timing closure.

06 / REPRODUCE

Explore and reproduce

  1. Select a complete subproject from the lab index.
  2. Inspect top-level, device, pins and IP paths in a compatible Quartus version.
  3. Compare results with the lab test matrix; a short ASCII work path can help rebuilds.
  4. For Lab 8, match Qsys addresses with hps_0.h and verify hardware and Linux software separately.

Scope and limitations
