# Pei An Chen - Engineering Portfolio

Personal engineering portfolio for embedded biomedical sensing, FPGA, research instrumentation, and cross-layer system integration.

## Local preview

```powershell
python -m http.server 8000 --directory site
```

Then open `http://localhost:8000`.

## Architecture

- `site/index.html`: semantic single-page content
- `site/style.css`: responsive engineering-console visual system
- `site/site.js`: theme, filtering, navigation, reveal, clock, and clipboard interactions
- `.github/workflows/deploy.yml`: static GitHub Pages deployment

Live site: <https://peianchen.github.io/peian-chen/>
